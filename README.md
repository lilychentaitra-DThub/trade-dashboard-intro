# 企業進出口數據看板 · 通用介紹簡報

中華民國對外貿易發展協會（TAITRA）數位科技中心「企業進出口數據看板」的通用介紹簡報，
單一 HTML 檔案，離線可用，適合對中小企業說明方案內容與申請方式。

視覺系統比照活動頁 [events.taiwantrade.com/115dashboard](https://events.taiwantrade.com/115dashboard/CMS/intro)。

## 使用方式

下載 `index.html` 用瀏覽器開啟即可，不需要網路（字型會從 Google Fonts 載入，離線時自動退回系統字型）。

### 操作

| 按鍵 | 功能 |
| --- | --- |
| `←` `→` | 換頁；第 2 頁會逐項揭露三個痛點 |
| `1`–`9` | 直接跳到指定頁 |
| `O` | 九頁縮圖總覽，點選跳頁（`Esc` 關閉） |
| `L` | 雷射筆，橘色光點跟隨游標 |
| `B` | 關閉／開啟逐項揭露 |
| `F` | 全螢幕 |

也支援觸控左右滑動換頁，以及 `index.html#5` 這種頁碼深連結。

第 6 頁的趨勢圖可以把滑鼠移到資料點上看數值，第 3 頁的方案項目與第 4 頁的比較表有懸停效果。
